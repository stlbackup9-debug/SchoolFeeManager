# School Fee Manager – User Guide

## First start
1. Open the app and log in with **admin / admin123**.
2. You must set a new password immediately.
3. Go to **Settings → School profile** and enter the school name (printed on receipts), address, phone, receipt prefix and the **academic-year start date** (used for due dates and the Overdue status).
4. Check **Settings → Fee rates**. They are pre-filled from the workbook's Fee_Rates sheet.
5. Optional: **Settings → Data → Import Excel workbook** to load students and past cash collections from `School_Fee_Management.xlsx`.
6. Create a Cashier account in **Settings → Users & roles**.

## Bottom navigation
**Dashboard** – totals (students, receivable, collected, outstanding, Day/Hostel), today's and this month's collection, receipts issued, students with balances, 6-month chart, class summary, recent transactions. Everything updates as soon as data changes.

**Students** – search by name or Student ID; filter by class, Day/Hostel, payment status, inactive. Tap a student for the profile: fee breakdown, balance, schedule and payment history (tap a payment to open its receipt).
* **Register** (Admin): enter name, class, Day/Hostel, New/Old, book type, payment term, discount %. The fee is calculated live as you type. The Student ID is generated automatically. The same name in the same class cannot be registered twice.
* **Edit**: changing class, type, New/Old, book type or discount re-assesses the fee with the current rates – you are shown old vs new Net before saving. Changing only the payment term re-splits the existing Net.
* **⋮ menu**: Promote / change class (optionally mark as Old and recalculate), Recalculate with current rates, Deactivate / Reactivate. Payments are always kept.

**Payments** – the payment schedule for every active student (3 installments or 12 months), with scheduled, paid, remaining and status. Expand a student and tap **Pay** next to an installment to collect it.

**Collection** – the cash register.
* **Collect**: choose the student (outstanding balance is shown), choose the installment/month (or General), enter the amount and date, then confirm. If the amount is more than the balance you must confirm the overpayment. Saving creates the transaction and a numbered receipt in one step and opens the receipt.
* **Receipt**: tap **Print** to print, or choose *Save as PDF* in the print dialog. Reprints are marked *DUPLICATE COPY*.
* **Register tab**: search by receipt number, name or ID; date filters. Admin can **void** a wrong entry (a reason is required). Voided entries stay visible and no longer count.
* **Daily / Monthly tabs**: collection summaries.

**Reports** – 10 reports. Each has filters (date range where relevant, class, student search, payment status, include inactive) and three buttons at the top: **Excel**, **PDF**, **Print**.

**Settings** – fee rates, recalculation, school profile, users, data (import/export/backup/restore), activity log, change password, log out.

## Changing fee rates
Saving new rates affects **new registrations only**. Existing students keep their approved assessment; their profile shows what the current rates would give. To apply new rates use *Recalculate* on one student or **Settings → Recalculate existing students** (all active students) – a confirmation shows how many students change and the total effect.

## Excel import
* Imports `Student_Register` (input columns B–F, N, Q, T), `Cash_Collection` (B–H) and `Fee_Rates`. `Payment_Schedule` and `Dashboard` are formulas, so they are regenerated by the app.
* A preview lists every error (row skipped) and warning before anything is saved. Students already in the app (same name and class) and receipt numbers already in the app are skipped, so importing the same file twice is safe.
* Cash rows are linked to students by name (and class if two students share a name), like Excel's SUMIF.

## Excel export
**Settings → Data → Export workbook** writes the five sheets in the original layout (values). The file can be imported again.

## Backup & restore
**Back up now** saves one `.db` file containing everything. Keep backups off the phone (Google Drive, computer, USB). **Restore** replaces all data with a backup after confirmation; the app keeps a safety copy of the data it replaced and restarts.
